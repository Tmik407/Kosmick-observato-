## Bezpečný bod pokračování
Pokračovat pouze novým požadovaným vylepšením. Neopakovat tvorbu PWA ani neměnit funkční jádro bez konkrétní potřeby.

## Co ověřit při příští změně
1. Načíst aktuální verzi dotčených souborů z větve main.
2. Zkontrolovat, zda se od posledního předání nezměnily.
3. Provést co nejmenší cílenou změnu.
4. Ověřit GitHub commit a výsledek nasazení.
5. Požádat o test na Androidu pouze tehdy, pokud je pro změnu nezbytný.
