# OPERATION X-5 — další úkoly

## Priorita 1 — ověření etapy 114 v UE5
- [ ] Otevřít projekt v kompatibilní verzi Unreal Engine 5.
- [ ] Vygenerovat projektové soubory a spustit Unreal Build Tool / Unreal Header Tool.
- [ ] Zkompilovat Development Editor a opravit případné chyby podle úplného výpisu.
- [ ] Otestovat změnu stavu posádky a paliva/munice a ověřit automatické `OnReportUpdated`.
- [ ] Ověřit lifecycle odpojení delegátů při ukončení komponenty.

## Priorita 2 — etapa 115
- [ ] Navázat od balíčku po etapě 114; neopakovat etapy 1–114.
- [ ] Zvolit další malý, konkrétní krok podle výsledků integrace a skutečného stavu projektu.
- [ ] Připravit dokumentaci, změněné soubory a ZIP balíček.
- [ ] Po etapě 115 provést větší integrační kontrolu celého projektu.

## Priorita 3 — první hratelný prototyp
- [ ] Připravit testovací bojiště a ověřit společné fungování klíčových systémů.
- [ ] Ověřit jednotky, rozkazy, boj, HUD a report v jedné misi.
- [ ] Evidovat chybějící assety, Blueprint nastavení a mapové závislosti.

## Priorita 4 — správa projektu
- [ ] Rozhodnout o založení samostatného GitHub repozitáře.
- [ ] Při založení repozitáře přesunout nebo zkopírovat dokumentaci a zdrojový balíček.
